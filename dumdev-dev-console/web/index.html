Release flow
  1. Commit the source changes.
  2. Build and verify the Apple silicon package locally.
  3. The authenticated owner can create a GitHub draft with Ollama notes and a SHA-256 sidecar.
  4. Review and publish the draft manually; no public release happens here.
Apple silicon macOS. Packages are ad-hoc signed, not notarized. New users must install Ollama, sign in to X, and explicitly grant required macOS permissions.
